## 🔄 BATCH GENERATION TIPS

1. **Consistency**: Use the same seed number for character variations
2. **Regional Styles**: Always include city-specific clothing/environment cues
3. **Lighting**: Match lighting across all assets (prefer dramatic side lighting)
4. **Color Palette**: Stick to dark backgrounds with neon accents
5. **Aspect Ratios**: 
   - Characters: 2:3 or 3:4
   - Environments: 1:1 for maps, 16:9 for backgrounds
   - Icons: 1:1
   - Weapons: 3:2

## 📝 EXAMPLE WORKFLOW

### Generating a New Gang Member:

1. Choose region (NYC/LA/Miami/Chicago/Detroit/NOLA)
2. Select base prompt for that region
3. Add specific traits:
   - Age range modifier
   - Clothing details
   - Tattoo specifications
   - Emotional expression
4. Add quality modifiers
5. Generate 4-8 variations
6. Select best, use seed for consistency
7. Generate additional poses with same seed
